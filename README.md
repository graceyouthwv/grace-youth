# 🌟 Grace Youth Campus Ministry Platform

**"Ace your Acads. Walk in Faith."**

A modern, full-stack campus ministry platform empowering college students across Western Visayas (Iloilo Province & City: ISUFST, UPV, CPU, WVSU, ISAT-U, USA) with free peer tutoring, campus life groups, youth camps & sponsorship, and 24/7 prayer wall support.

---

## 🚀 Key Features

* 📚 **Free Peer Academics & Tutors:** 1-on-1 tutoring sessions, mock reviewers, and smart request matching.
* 🌱 **Campus Life Groups & Discipleship:** Small groups in dorms & cafes, 1-on-1 spiritual mentoring, and student-initiated group proposals.
* 🏕️ **Youth Camps & Sponsorship Campaigns:** Seed funding to sponsor freshmen for youth camps, exam survival outreach, and campus worship nights.
* 🙏 **24/7 Prayer & Praise Wall:** Real-time prayer requests, praise reports, and intercession counters.
* 🛡️ **Role-Based Portals:** Dedicated dashboards for Students, Volunteer Peer Tutors, Campus Youth Workers, and Ministry Admins.
* 📲 **PWA & Offline Ready:** Fast native feel on iOS, Android, and Desktop with offline caching.

---

## 🛠️ Tech Stack

* **Frontend:** React 19, Vite, Tailwind CSS v4, Lucide Icons, Canvas Confetti
* **Design:** High-contrast light & dark themes with accessibility compliance
* **Backend Integration:** PostgreSQL & Supabase Realtime schema ready

---

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/graceyouthwv/grace-youth.git

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
